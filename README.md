//# Password Strength Checker

A Python command-line tool that rates password strength and tells you what to improve.

## Features
- Checks length, uppercase, lowercase, and special characters
- Hides input while typing
- Gives feedback on what is missing

## How to run
```
python password_checker.py
```

## Example output
```
Enter your password:
It's a weak password
 - Add at least one special character
```

## Note
Passwords are never stored or logged. This is a learning project, not a production tool.
